# ClarifAI Datasets

> This repository functions as a single location to access, edit, and manage the test-in-house and synthetically generated datasets used to evaluate the ClarifAI web application and LLM-assisted clarification pipeline used in ClarifAI.

## Datasets
**SimpleQA**: Built for LLM-based contextual relevance classification evaluation.
**SimpleQA2**: Built for LLM-based contextual relevance classification evaluation.
**VAQA**: Built for LLM-based vagueness/ambiguity identification/classification evaluation.
**Synthetic PI Feedback V1**: Built for LLM-based contextual relevance and vagueness/ambiguity classification evaluation.
**Synthetic PI Feedback V2**: Built for LLM-based contextual relevance and vagueness/ambiguity classification evaluation.
