# SimpleQA2

> This small test dataset contains 25 unique question-answer pairs with 5 questions and 5 answers to each question. This dataset was originally created to evaluate the Telemetry module in the ClarifAI LLM-assisted clarification pipeline, to conduct contextual relevance classifications. Building upon SimpleQA, the answers in this dataset mix contextually relevant content with contextually irrelevant content, slightly increasing the complexity and realism of software feedback, in comparison to SimpleQA. Answers in this dataset are labeled by two columns: CR Ratio and label. Label is a binary contextual relevance classification, identical to SimpleQA version 1. CR Ratio is the proportion of contextually relevant clauses in a given answer, labeled as a ratio of contextually relevant/contextually irrelevant clauses.
